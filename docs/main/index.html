    Клубок

    Совместная бесконечная доска для блок-схем со связями, описывающих алгоритмы или процессы. У каждого блока или связи можно оставлять комментарии в режиме чата для обсуждения элемента.

    Особенности

    💯 Бесплатный и с открытым исходным кодом. 🎨 Бесконечная доска на основе canvas. 💾 Автосохранение. 📤 Экспорт в PNG, JSON (.klubok). 📥 Импорт из JSON (.klubok). 🖼️ Поддержка изображений. 🌓 Тёмный режим. 🧰 Широкий выбор инструментов: прямоугольник, круг, ромб, стрелка, текст, контейнер. ➡️ Привязка стрелок. 🔍 Поддержка масштабирования и панорамирования.

    Документация

    • Начало работы: Установка
    • Администрирование: Обновление, Фича-флаги, Метрики, Хранилище изображений, Политика обработки персональных данных
    • Прокси: Nginx
    • База данных: PostgreSQL
    • Разработка: Локальный запуск, Релиз, Версии инструментов
