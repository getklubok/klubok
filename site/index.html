Быстрый старт

Запуск за несколько команд

Клубок поставляется как Docker-образ. PostgreSQL поднимается в контейнере, а nginx направляет запросы на активное окружение.

  1. Скачайте compose-файлы для схем Blue-Green из каталога deploy/ .
  2. Заполните конфигурацию: домен, пароли PostgreSQL и почты, адреса приложения.
  3. Запустите контейнер blue и включите конфиг nginx — приложение готово.
Полная инструкция Понадобятся Docker Compose и nginx
terminal 
# Перейдите в каталог с compose-файлами
cd /opt/klubok

# Задайте версию и запустите Blue
docker network create klubok-network
export D=blue APP_VERSION=X.Y.Z
docker compose -f ./compose.${D}.yaml up -d

FAQ

Частые вопросы

Что нужно для установки?

Docker с плагином Compose, nginx и домен. PostgreSQL запускается в контейнере, а данные хранятся в Docker volume.

Где хранятся данные?

На вашем сервере, в вашей базе PostgreSQL. Клубок не требует внешнего облака — резервными копиями и доступом управляете вы.

Как обновляться без простоя?

По схеме Blue-Green: новое окружение поднимается рядом со старым, после чего nginx переключается на него. Старое остаётся для быстрого отката. Подробности — в документации по обновлению .

Можно ли включить вход по email или SSO?

Да. Вход по email-коду и OIDC SSO включаются фича-флагами FEATURE_AUTH_EMAIL_ENABLED и FEATURE_AUTH_SSO_ENABLED . По умолчанию работают обезличенные автоаккаунты.

Можно ли встроить диаграмму на сайт?

Да, через embed-код. Параметр ?theme=system , ?theme=light или ?theme=dark подстроит оформление под страницу.

Под какой лицензией распространяется Клубок?

Под GNU AGPL v3. Проект можно использовать, изучать и дорабатывать; при распространении изменённой версии действуют условия лицензии. Полный текст — в репозитории .
